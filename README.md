Meeting notes for Production team
==================================


This repository holds our public meeting notes.
The ESA production team is proud in its openness and wish to continue with this by going even more open.

This way, we do not need a single secretary or notetaker, but can instead each make use of the infrastructure availible to us through Git to submit and amend notes.



Contributing
------------

In general we do not accept public contributions, mainly because the public is not invited to the meetings and would therefor not know what was discussed.
But if you where to notice a spelling error or such, feel free to make a pull request and we will have a look. 
Please strive for small commits and small patches with limited scope. If you are fixing punctuation errors, stick to that. Fixing various issues? Keep it to a single file at a time.
